# SE VOULOIR BELLE

SE VOULOIR BELLE 是一个完全由 HTML5、CSS3 和 Vanilla JavaScript 构建的离线个人美妆咨询与创意妆容平台。无需 npm、构建工具、CDN、在线字体、远程图片、API 或后端程序；入口文件为根目录的 `index.html`。

## 功能

- 可编辑档案：图例化五官特征、六类独立色彩偏好、质地、包装、成分排除
- 24 条本地产品数据：12 条来源待复核的实际产品资料，以及 12 条明确标记的 SE VOULOIR BELLE 功能演示数据
- 规则推荐：先处理预算、排斥色、质地和成分硬条件，再按用户可调权重输出 Top 3
- 三级分类：使用部位 → 产品类型 → 产品形态；妆效、组合形式和性能作为独立标签
- 专业性能偏好：持妆、颜色稳定、成膜、转移、叠加、光泽、闪粉与证据可信度
- 零结果诊断：实时候选计数、逐项排除原因及不会自动放宽硬条件的恢复操作
- 化妆包：添加、编辑、删除、搜索、收藏、重复检查及本地照片辅助批量录入
- 合照录入：拖动框选多件产品、逐项人工确认、选择性保存；不宣称自动识别
- 日常与创意妆容：优先读取已有产品，提供本地参考图、色板、步骤、安全提醒及保存
- 专业肤色描述：深浅、底调、表面状态与对比度独立记录；自然光照片只做本地亮度辅助
- 七类独立颜色档案：主色、偏色、偏色强度、优先级及动态 HSL 关系示意
- 13 类独立预算、定妆习惯、产品厚薄涂示意、持妆证据和六种基础灯光预览
- 新手学院：模式、问答、预算化入门建议、七课进度
- 穿搭建议、购买渠道记录、正品检查、促销计算、JSON 导入导出和清除数据

## 离线运行

直接双击 `index.html` 即可运行。也可以使用任意静态服务器预览。所有核心文件和图片均使用相对路径；商品来源仅作为文字记录，不会在页面加载时发起网络请求。

用户数据存入 `localStorage`。若浏览器在 `file://` 下限制持久存储，当前页面仍可操作，并会提示保存失败；可以使用购物指南页的 JSON 导出保存数据。

## 数据说明

真实品牌条目用于课程展示，价格有录入日期，来源链接状态标为待复核。完整成分表不足时会显示“待核实”，不会声称产品不含某成分。SE VOULOIR BELLE 演示条目是本地功能示例数据，不代表真实在售商品。

自然光照片分析不会上传图片，也不会自动判断底调或粉底色号。厚薄涂色块与灯光切换均明确标记为基础模拟示意，不属于真实试色、氧化测试或物理照明预测。更可靠的人脸分析、产品实测与生成式图像需要合规的独立服务和授权数据；本静态版本没有伪装这些能力。
